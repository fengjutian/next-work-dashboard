# OfficeCLI binary location

Place the OfficeCLI executable for each release target here before packaging:

- `win-x64/officecli.exe`
- `win-arm64/officecli.exe`
- `darwin-x64/officecli`
- `darwin-arm64/officecli`
- `linux-x64/officecli`
- `linux-arm64/officecli`

Office Studio also detects `OFFICECLI_PATH` and OfficeCLI on `PATH` during development.
Keep the upstream Apache-2.0 `LICENSE`, `NOTICE`, and third-party notices beside redistributed binaries.
