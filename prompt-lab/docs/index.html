next-work-dashboard

基于 Electron 的 AI 提示词注入桌面应用 — 打开任意 AI 网站，一键注入预设提示词，提升 AI 交互效率。

GitHub 仓库 项目介绍 & 部署 插件架构

核心能力

🌐 多站点 WebView — 同时打开 DeepSeek、ChatGPT、Kimi 等
⚡ 一键注入 — 点击提示词自动填入 AI 输入框
📦 提示词管理 — CRUD + 分类/标签/变量模板
🔍 Spotlight 面板 — Ctrl+K 全局搜索
🧩 插件系统 — 双层架构，支持用户自定义 JS 插件
🔒 纯本地 — 无需 API Key，数据不上传

技术栈

层选型

快速开始

git clone https://github.com/fengjutian/next-work-dashboard.git
cd next-work-dashboard/prompt-lab
npm install
npm start

构建分发

npm run make  # 产出 Windows .exe / macOS .zip / Linux .deb .rpm
