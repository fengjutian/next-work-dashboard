# 快速开始

## 环境要求

- Windows、macOS 或 Linux
- Node.js 20 或更高版本（仅开发时需要）
- 至少 4 GB 可用内存

## 本地开发

```bash
git clone https://github.com/your-org/next-work-dashboard.git
cd next-work-dashboard/prompt-lab
npm install
npm run dev
```

## 下一步

启动应用后，从设置中的插件管理器启用需要的功能。建议先从 Work Browser 和知识工作空间开始。
