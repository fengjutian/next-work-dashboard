# 插件指南

Next Work Dashboard 通过插件扩展能力。功能可以拥有自己的界面、命令、设置和生命周期。

## 内置能力

| 插件 | 用途 | 默认状态 |
| --- | --- | --- |
| Work Browser | AI 辅助研究、网页归档与任务执行 | 关闭 |
| Knowledge Workspace | 管理文档、笔记与语义检索 | 开启 |
| Media Tools | 音视频预览、转录与分享 | 按需开启 |

## 启用插件

打开 **设置 → 插件**，找到目标插件并切换启用状态。部分插件需要额外配置 API 密钥或本地 sidecar。
