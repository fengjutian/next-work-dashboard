Plugin Platform · API v1

安全、可组合的插件系统

内置插件提供深度集成，用户插件统一运行在 iframe Sandbox 中，通过受控 Bridge 使用宿主能力。

当前事实来源：此页提供架构速览；接口字段、SDK 示例和发布检查清单以 Markdown 完整文档及源码类型为准。

架构总览

Trusted

内置 React 插件

随应用编译，运行于宿主 React 树，可提供编辑器、终端和 Office 等深度能力。

Untrusted

用户 Sandbox 插件

运行在不含 allow-same-origin 的 iframe，通过消息协议请求显式授权的能力。

Built-in React plugins ───────────────┐
                                      ├─ PluginRegistry ─┬─ Activity Bar
User .nwd ─ iframe Sandbox ─ Bridge ─┘                  ├─ Main Panel
                                                         ├─ Command Palette
                                                         └─ Status Bar

Kernel 用户插件已经移除。用户提供的代码不得在 Renderer 宿主上下文通过 new Function() 执行。

注册与生命周期

PluginRegistry 统一管理声明、启用状态、命令、激活以及资源回收。React 视图通过外部 store 订阅注册表变化。

inactive ── activate() ──▶ activating ──▶ active
   ▲                                           │
   └──────── cleanup ◀── deactivating ◀────────┘

activation failure ──▶ error

插件禁用、覆盖或卸载时，宿主会清理通过 context 注册的订阅和命令，避免残留监听器。

Sandbox 安全边界

DOM

页面隔离

iframe 无同源权限，不能直接读取宿主 DOM、Cookie 或 localStorage。

IPC

协议校验

Bridge 校验消息来源、结构、参数数量、大小与请求超时。

ACL

显式授权

Manifest 声明权限，用户授权后对应 API 才能执行。

权限模型

权限能力注意事项
store.read读取插件私有存储按插件 ID 隔离
clipboard剪贴板访问涉及用户敏感内容
inject向目标站点注入内容需要目标页面上下文
external.open打开外部链接仅允许安全协议
data / preview宿主数据与预览能力按 API 参数继续校验
file.read / file.write授权范围内的文件操作必须经过宿主文件边界

.nwd v1 插件包

`.nwd` 是不超过 2 MB 的 UTF-8 JSON 文件。客户端会校验格式、Manifest、语义版本、权限、运行时和非空脚本。

{
  "format": "nwd-v1",
  "manifest": {
    "id": "example.dashboard",
    "name": "Example Dashboard",
    "version": "1.0.0",
    "apiVersion": "1",
    "runtime": "sandbox",
    "permissions": ["store.read", "data"]
  },
  "script": "PluginSDK.ui.setContent('<h1>Hello</h1>')",
  "style": null
}

推荐开发流程

1

2

本地验证

3

打包发布

检查版本、API v1、Sandbox 和 2 MB 上限后导出。
