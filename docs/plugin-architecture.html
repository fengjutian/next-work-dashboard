Registry 与生命周期

PluginRegistry 统一负责注册、启用状态、命令、生命周期和资源回收。React 组件通过基于 useSyncExternalStore 的 usePluginRegistryVersion() 订阅变化。

inactive → activating → active
    ↑                       │
    └──── deactivating ─────┘

激活异常 → error

插件可以实现异步 activate(context) 和 deactivate()。通过 context.subscriptions.add() 与 context.commands.register() 注册的资源，会在禁用、覆盖或卸载时自动清理。

Sandbox 安全约束

  • iframe 不启用 allow-same-origin，不能直接读取宿主 DOM 和存储。
  • Host 校验消息来源、协议结构、参数数量和 256 KB 消息上限。
  • SDK 请求具有 30 秒超时。
  • 8 类权限控制 Store、剪贴板、注入、外链、数据、预览和文件操作。
  • 私有存储按插件 ID 隔离，单插件限制 512 KB。
  • 外链只允许 HTTP、HTTPS 和 mailto，禁止 URL 内嵌凭据。

导入器会校验 2 MB 文件上限、格式、语义版本、API 版本、ID、权限、运行时和代码字段。Kernel 包还需要显式高风险确认。

Kernel 风险

Kernel 仍通过 new Function() 在 Renderer 中执行。注入 API 白名单不能构成恶意代码隔离；真正的隔离需要 Electron Utility Process。在此之前只能安装完全可信的 Kernel 插件。
