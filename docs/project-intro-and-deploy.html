开发、构建并交付本地优先的 AI 工作台

Next Work Dashboard 将 AI 网站、提示词、知识库、代码编辑、终端和插件能力组织在一个可扩展的桌面应用中。

产品定位

它不是重新实现 AI 网站的聊天客户端，而是保留官方网站体验，在桌面工作台中统一管理站点、上下文、提示词和本地工具。

AI

多站点协作

通过 WebView 使用不同 AI 网站，并将提示词和上下文注入当前会话。

DB

本地数据

工作区配置和业务数据优先保存在用户设备，敏感令牌使用系统能力保护。

SDK

插件扩展

内置插件深度集成，用户插件通过 Sandbox 与权限 Bridge 安全扩展。

本地开发

命令目录：除 Git 操作外，以下 npm 命令默认在仓库的 prompt-lab 目录运行。

git clone https://github.com/fengjutian/next-work-dashboard.git
cd next-work-dashboard/prompt-lab
npm install
npm start

Windows 原生依赖需要可用的 Node.js 构建工具链。若依赖安装或 Electron 原生模块重建失败，先查看 故障排查。

质量检查

Types

npm run typecheck

验证 TypeScript 类型边界。

Style

npm run lint

检查代码质量和工程约定。

Tests

npm test

运行 Vitest 自动化测试。

提交前应运行项目定义的一键检查命令；准确脚本以 prompt-lab/package.json 为准。

构建与发布

npm run package   # 生成未安装的应用目录
npm run make      # 生成当前平台分发产物

Electron Forge 默认针对当前系统构建。跨平台发布建议在对应操作系统的 CI Runner 上执行，并在发布前完成原生依赖重建和安装包烟雾测试。

数据与备份

应用数据位于 Electron 的 userData 目录，不同操作系统路径不同。提示词、站点、设置、知识库、插件与会话数据可能分布于数据库、Local Storage 和工作区文件。

Backup

备份整个 userData

关闭应用后复制完整目录，能够避免遗漏数据库旁路文件或插件状态。

Secrets

不要手工迁移密文

safeStorage 密文可能绑定当前系统账户或密钥链，跨机器恢复需要重新配置令牌。
