# next-work-dashboard 用户手册

## 1. 开始使用

next-work-dashboard 是一个 Electron 桌面工作台，集成 AI 站点、提示词、对话、代码编辑、终端、文档预览和插件系统。

开发环境启动：

```powershell
cd prompt-lab
npm install
npm start
```

首次启动后，建议先完成 AI API、AI 站点和外观设置，再启用需要的模块。

## 2. 界面结构

- 顶部菜单：文件、模块、视图和窗口控制。
- 左侧活动栏：切换已启用插件和设置。
- 主区域：显示当前插件面板。
- 状态栏：显示插件贡献的状态信息。

`Ctrl+1` 返回 AI 工作台，`Ctrl+,` 打开设置。

## 3. AI 站点与提示词

在“设置 → AI 站点”维护站点地址、输入框选择器和提交按钮选择器。站点页面变化后，如果提示词无法注入，通常需要更新选择器。

提示词模块支持分类、标签、收藏、置顶、变量填充和注入记录。包含变量的提示词在发送前会要求填写变量值。

不要在提示词、会话或插件私有数据中保存 API 密钥；密钥应通过专用设置入口保存。

## 4. 文件与代码编辑

使用“文件 → 打开文件…”选择文件。宿主会按照扩展名和插件优先级选择 Word、Excel、PPT、PDF 或代码编辑器。

代码编辑器支持工作区、文件树、搜索、Git、终端、差异预览和 AI 辅助编辑。进行批量替换、AI 修改或 Git 回滚前，应先确认差异并保留未提交工作。

部分文件编辑器对统一打开事件的支持仍在完善；如果没有直接打开文件，请进入目标插件后使用其“打开”按钮。

## 5. 插件管理

插件分为：

- 内置插件：随应用构建，运行在受信任的 Renderer 环境。
- 用户插件：运行在 iframe Sandbox，只能通过 `PluginSDK` 请求宿主能力。

用户 Kernel 插件已经移除，不能创建、导入或执行。

### 安装

1. 打开“插件管理”。
2. 点击“导入”，选择 `.nwd` 文件。
3. 检查导入结果和插件申请权限。
4. 在“设置 → 插件”撤销不需要的权限。

只安装来源可信的插件。Sandbox 能降低风险，但不能替代对插件来源和权限的判断。

### 启用、禁用和删除

- 卡片右上角开关用于启用或禁用。
- 禁用插件会隐藏入口并停止生命周期资源。
- 删除用户插件前，先按需要导出备份。

### 更新与回滚

导入相同 ID 的插件会执行覆盖更新，并保留最近 5 个版本快照。插件卡片提供上一版本回滚入口。当前更新健康检查和失败自动回滚仍在开发，重要更新前请先导出备份。

### 日志、熔断和安全模式

- 插件卡片的“日志”入口可查看最近错误。
- 用户插件连续发生 3 次运行错误会被熔断禁用。
- 安全模式会禁用全部用户插件，用于排查启动或运行问题。

## 6. 数据与备份

业务数据主要由应用数据库保存；用户插件定义、授权、配置和私有数据当前存储在统一的 LocalStorage 平台记录中。

备份前应退出正在进行的编辑和终端任务。插件更新前可导出 `.nwd`；完整数据目录和自动备份能力仍需进一步完善。

## 7. 常用操作

| 操作 | 方式 |
|---|---|
| AI 工作台 | `Ctrl+1` |
| 设置 | `Ctrl+,` |
| 打开文件 | 文件菜单，`Ctrl+O` 提示已显示；完整快捷键监听仍需完善 |
| 重新加载界面 | 视图 → 重新加载 |
| 关闭窗口 | `Alt+F4` |
