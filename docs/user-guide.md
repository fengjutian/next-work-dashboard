# 📖 next-work-dashboard 用户手册

> 从零开始，掌握 AI 工作台的日常使用。

---

## 1. 快速开始

### 1.1 启动应用

```bash
cd prompt-lab
npm install
npm start
```

### 1.2 首次设置向导

首次启动后，建议按以下顺序配置：

1. **AI API**：`设置 → AI API`，配置 API Key、模型与 Base URL（可选，官网注入模式无需）
2. **知识库**：`设置 → 知识库`，选择 Memory Provider 与 Embedding 方案（本地 / OpenAI 兼容）
3. **AI 站点**：`设置 → AI 站点`，确认预设站点可用，或添加自定义站点
4. **外观 / 快捷键**：`设置 → 外观` 选择亮色 / 暗色 / 跟随系统；`设置 → 快捷键` 查看或自定义全局快捷键
5. **启用模块**：在左侧活动栏打开需要的功能面板

设置面板共 **8 个 Tab**：AI API / 知识库 / AI 站点 / 插件 / 外观 / 快捷键 / 数据管理 / 关于。

## 2. 界面结构

```
┌──────┬────────────────────────────────────────┐
│ 活动栏 │         主面板区域                       │
│      │                                        │
│ ✨ AI │   当前激活的插件面板显示在这里              │
│ 💬 聊 │                                        │
│ 📝 提 │                                        │
│ 📚 知 │                                        │
│ 🕸️ 图 │                                        │
│ 🔧 插 │                                        │
│ 🗄️ 库 │                                        │
│ ⚙️ 设 │                                        │
│      ├────────────────────────────────────────┤
│      │         状态栏（插件贡献的状态信息）        │
└──────┴────────────────────────────────────────┘
```

- **活动栏**（左侧）：切换已启用插件和设置入口
- **主面板**（中央）：当前插件的完整界面
- **状态栏**（底部）：显示当前注入模式、连接状态等
- **菜单栏**（顶部）：文件 / 模块 / 视图
- **快捷键**：`Ctrl+1` 回到 AI 工作台，`Ctrl+,` 打开设置

> 活动栏条目随插件启用/禁用动态增减（默认启用 14 个内置插件）。

## 3. AI 站点与提示词

### 3.1 配置 AI 站点

`设置 → AI 站点` 中可以：

| 操作 | 说明 |
|---|---|
| 启用 / 禁用 | 控制站点是否出现在标签栏 |
| 添加自定义 | 输入名称、URL、输入框选择器 |
| 编辑选择器 | 站点改版后更新 CSS 选择器 |
| 调整顺序 | 修改 `sortOrder` 改变标签页顺序 |

> ⚠️ 站点页面 HTML 变化后，如果提示词无法注入，通常需要更新选择器。

### 3.2 管理提示词

在提示词面板中：

| 功能 | 操作 |
|---|---|
| 新建 | 填写标题、正文、选择分类和标签 |
| 变量 | 正文中使用 `{{变量名}}` 占位符 |
| 搜索 | 按标题 / 正文 / 标签模糊搜索 |
| 过滤 | 按分类或标签筛选列表 |
| 收藏 | 点击星标，常用提示词优先显示 |
| 置顶 | 点击图钉，固定在列表顶部 |

### 3.3 注入提示词

1. 在标签栏切换到目标 AI 站点
2. 在提示词面板点击需要的提示词
3. 如有变量，在弹出的面板中填写
4. 提示词自动填入 AI 输入框

| 注入模式 | 行为 |
|---|---|
| **仅填充** | 填入输入框，不发送 |
| **填充并发送** | 填入输入框后自动点击发送按钮 |
| **替换** | 清空输入框后填入 |
| **追加** | 在现有内容末尾追加 |

在底部状态栏可切换注入模式和追加/替换策略。

> 🔐 不要在提示词、会话或插件私有数据中保存 API 密钥；密钥应通过专用的 `设置 → AI API` 入口保存（safeStorage 加密）。

## 4. 文件与代码编辑

### 4.1 打开文件

- **菜单**：`文件 → 打开文件…`
- **快捷键**：`Ctrl+O`

应用会根据文件扩展名自动选择对应的编辑器（`resolveFileEditor`）：

| 文件类型 | 打开工具 |
|---|---|
| `.docx` / `.doc` | Word 预览 / Office Studio |
| `.xlsx` / `.xls` / `.csv` | Excel 编辑器 / Office Studio |
| `.pptx` / `.ppt` | PPT 预览 / Office Studio |
| `.pdf` | PDF 预览 |
| 代码文件 | 代码编辑器 |

### 4.2 代码编辑器

代码编辑器支持：

- 📁 工作区文件树管理
- 🔍 跨文件搜索
- 🔀 Git 集成（历史、差异、提交、冲突处理）
- 🖥️ 内置终端
- 📊 差异预览（Diff View）
- 🤖 AI 辅助编辑（自动创建隔离 Worktree，仅用户可合并）

> ⚠️ 批量替换、AI 修改或 Git 回滚前，请先确认差异并保留未提交工作。

## 5. 插件管理

### 5.1 插件类型

| 类型 | 运行位置 | 信任级别 | 来源 |
|---|---|---|---|
| **内置插件** | Renderer 进程 | 完全信任 | 随应用构建（23 个） |
| **用户插件** | iframe Sandbox | 低信任 | `.nwd` 文件导入 |

> ⚠️ 用户 Kernel 插件已移除，不能创建、导入或执行。

### 5.2 安装用户插件

1. 打开 **插件管理**
2. 点击 **导入**，选择 `.nwd` 文件
3. 检查导入结果和插件申请的权限
4. 在 `设置 → 插件` 撤销不需要的权限

> 🔐 只安装来源可信的插件。Sandbox 降低风险但不能替代对来源的判断。

### 5.3 管理插件

| 操作 | 方式 |
|---|---|
| 启用 / 禁用 | 卡片右上角开关 |
| 查看日志 | 卡片"日志"入口 |
| 删除 | 先导出备份，再删除 |
| 回滚 | 卡片提供上一版本回滚（保留 5 个快照） |

### 5.4 安全机制

- 用户插件连续 **3 次运行错误**会被熔断禁用
- **安全模式**会禁用全部用户插件，用于排查启动问题
- 导入相同 ID 的插件会覆盖更新，保留最近 5 个版本快照

## 6. 数据与备份

| 数据 | 存储位置 |
|---|---|
| 业务数据（提示词 / 站点 / 设置 / 会话 / 技能） | 应用 SQLite 数据库（`<userData>/next-work-dashboard.db`） |
| 插件定义 / 授权 / 配置 | 统一 LocalStorage（`plugin-platform-state-v1`） |
| API Token | OS 原生安全存储（加密文件 `<userData>/.auth-tokens.enc`） |
| 对话历史 / 记忆 | Markdown 文件（`<documents>/next-work-dashboard/`） |

### 备份建议

- 备份前退出正在进行的编辑和终端任务
- 插件更新前导出 `.nwd` 备份
- 定期导出提示词数据（`设置 → 数据管理 → 导出`）
