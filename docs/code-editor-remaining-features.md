# 代码编辑器未完成功能清单

> 更新日期：2026-08-01  
> 范围：Git、AI 编辑、终端、文件资源管理器、工作区搜索  
> 状态定义：`未开发`、`部分完成`、`待增强/验收`

## 1. 总体优先级

| 优先级 | 目标 | 说明 |
|---|---|---|
| P0 | 数据安全与可恢复 | 冲突合并、替换预览与撤销、AI Patch 审核、终端任务退出与错误处理 |
| P1 | 日常开发闭环 | Git 分支/远端完整管理、多根工作区、搜索编辑器、终端分屏与任务系统 |
| P2 | 高级 IDE 体验 | Git 图形历史、AI Agent 连续会话、终端屏幕恢复、Explorer 紧凑目录与高级过滤 |

## 2. Git

### 2.1 分支管理（部分完成，P1）

已具备创建、切换和当前分支显示。仍需：

- [ ] 删除本地分支，并阻止误删当前分支。
- [ ] 重命名分支。
- [ ] 展示本地分支、远程分支、上游分支和 ahead/behind 数量。
- [ ] 从远程分支检出并自动建立 tracking。
- [ ] 分支切换前检测脏文件、冲突和未跟踪文件覆盖风险。
- [ ] 用应用内对话框替代 `window.prompt`。
- [ ] 分支操作完成后刷新文件树、编辑器内容、Git 装饰和历史。

验收：在有未提交修改、无上游、远程分支重名等情况下均给出可理解反馈，不能静默丢失文件。

### 2.2 拉取、推送、Fetch 与同步（部分完成，P0）

已有 Fetch/Pull/Push/Sync IPC 和进度状态。仍需：

- [ ] 显示当前远端、上游和 ahead/behind。
- [ ] Pull 策略配置：FF-only、merge、rebase。
- [ ] 首次 Push 时选择远端并设置 upstream。
- [ ] Push force-with-lease 二次确认；禁止直接暴露 `--force`。
- [ ] 支持取消长时间网络操作。
- [ ] 显示传输进度，而不只是 started/completed。
- [ ] 区分网络、代理、证书、权限、仓库不存在和凭据过期错误。
- [ ] 操作失败后提供“在终端重试”和“打开凭据设置”入口。

### 2.3 提交历史与 Commit Diff（部分完成，P1）

已有最近 100 条提交和原始 Commit Patch 输出。仍需：

- [ ] 历史分页、无限滚动和按作者/日期/消息筛选。
- [ ] 图形化分支拓扑线。
- [ ] Commit 详情展示父提交、分支、Tag、变更文件和增删行数。
- [ ] 点击 Commit 文件后使用 Monaco Diff，而不是只显示原始 Patch 文本。
- [ ] 支持双 Commit 比较。
- [ ] Copy Commit ID、Checkout Commit、Create Branch/Tag from Commit。
- [ ] 提交签名状态和 GPG/SSH 签名错误提示。

### 2.4 文件时间线（部分完成，P1）

已有按文件调用 Git log 的入口。仍需：

- [ ] 独立 Timeline 视图，不覆盖全仓库历史状态。
- [ ] 展示每次提交中的文件状态：新增、修改、重命名、删除。
- [ ] 查看任意历史版本内容及与当前文件比较。
- [ ] 恢复历史版本前显示 Diff，并保留撤销点。
- [ ] 补充本地保存历史，不依赖 Git 提交。

### 2.5 行内 Git 修改标记（部分完成，P1）

已有基于 `git diff --unified=0` 的新增/修改/删除行装饰。仍需：

- [ ] 点击 gutter 标记弹出 Peek Diff。
- [ ] 删除行标记显示准确的删除位置和原内容。
- [ ] 支持 staged 与 unstaged 两套颜色/状态。
- [ ] 保存、切换分支、暂存后增量刷新，避免频繁运行整文件 diff。
- [ ] 大文件和大型仓库性能节流。
- [ ] 行级回滚、复制旧内容和暂存入口。

### 2.6 单 Hunk 暂存（部分完成，P0）

已有 Hunk Patch 提取和 `git apply --cached` 暂存。仍需：

- [ ] Hunk 列表视图与变更行预览。
- [ ] 单 Hunk 取消暂存。
- [ ] 行级选择后生成最小 Patch。
- [ ] Patch 上下文失效时自动刷新并提示，而不是只显示 Git 原始错误。
- [ ] 新文件、删除文件、重命名和二进制文件的特殊处理。
- [ ] Hunk 回滚工作区修改及二次确认。

### 2.7 Merge Editor 与冲突解决（部分完成，P0）

当前可以读取 base/ours/theirs，并整文件选择 ours 或 theirs。仍需：

- [ ] 三栏或四栏 Merge Editor：Base、Current、Incoming、Result。
- [ ] 按冲突块接受 Current、Incoming、Both 或手工编辑 Result。
- [ ] 冲突块导航、冲突计数和全部接受操作。
- [ ] 识别 content、add/add、delete/modify、rename/rename 冲突。
- [ ] 只有所有冲突标记消除后才能标记 resolved。
- [ ] Continue Merge/Rebase/Cherry-pick 和 Abort 操作。
- [ ] 关闭 Merge Editor 前保护未保存的合并结果。

### 2.8 Stash、Tag 与 Remote（部分完成，P1）

已有基础 IPC 和简易按钮。仍需：

- [ ] Stash 独立列表、详情 Diff、重命名、Apply、Pop、Drop 确认。
- [ ] 只 Stash staged、包含/排除未跟踪文件。
- [ ] Tag 详情、annotated/lightweight 类型、从指定 Commit 创建。
- [ ] 推送/删除远程 Tag。
- [ ] Remote 结构化列表、编辑 URL、区分 fetch/push URL。
- [ ] 设置默认 Remote、测试连接和打开远端仓库页面。
- [ ] 移除 Remote/Tag/Stash 使用应用内确认框。

### 2.9 Git 进度与凭据（部分完成，P0）

- [ ] 可取消操作和超时控制。
- [ ] 同一工作区 Git 操作串行队列，避免并发写索引。
- [ ] 操作日志独立 Output Channel。
- [ ] Git Credential Manager、SSH Agent 和系统 Keychain 状态检测。
- [ ] 不记录 Token、密码和带凭据的 Remote URL。
- [ ] 对 index.lock、detached HEAD、shallow clone、safe.directory 给出专门引导。
- [ ] 对可能破坏历史的操作进行明确风险提示。

## 3. AI 编辑

### 3.1 多文件 AI 修改（部分完成，P0）

当前能自动选择最多约 10 个候选文件，并解析 AI 返回的整文件 JSON。仍需：

- [ ] 支持新建、删除、重命名文件，不只修改已有文件。
- [ ] 工作区级变更计划：先展示计划，再生成 Patch。
- [ ] 限制允许修改的路径和文件类型，拒绝越界路径。
- [ ] 检测 AI 生成期间文件是否被用户或外部程序修改。
- [ ] 原子接受多个文件；任一文件冲突时不产生半完成状态。
- [ ] 大文件按片段发送，避免把完整文件全部塞入上下文。

### 3.2 Agent 自动搜索相关文件（部分完成，P1）

当前按指令关键词和已打开文件做轻量排序。仍需：

- [ ] 基于符号定义、引用、import 图和 Problems 自动扩展上下文。
- [ ] 使用全文搜索结果而非仅文件名关键词。
- [ ] Agent 可迭代执行“搜索→读取→计划→修改”，并限制最大轮次。
- [ ] 显示 Agent 每次读取了哪些文件及原因。
- [ ] `.gitignore`、敏感文件和用户排除规则必须生效。

### 3.3 Patch/Hunk 级接受与拒绝（未开发，P0）

- [ ] AI 响应转换为统一 Patch 数据模型。
- [ ] 每个文件、每个 Hunk 分别接受或拒绝。
- [ ] 单行/选区级接受。
- [ ] 接受一个 Hunk 后重新计算剩余 Diff。
- [ ] Patch 无法应用时提供三方合并，而不是覆盖当前内容。
- [ ] 审阅完成前保留候选队列，切换标签不能丢失。

### 3.4 AI Inline Edit（未开发，P1）

- [ ] 选中代码后使用快捷键打开内联输入框。
- [ ] 以 Ghost Text 或 Inline Diff 展示候选。
- [ ] Enter 接受、Escape 拒绝、快捷键切换候选。
- [ ] 只修改选区时保持周边代码和光标位置。
- [ ] 支持继续追问与重新生成。

### 3.5 Problems 修复与测试生成（部分完成，P1）

已有 Problems“AI 修复”和“生成测试”提示入口。仍需：

- [ ] 自动附带诊断代码、相关代码片段、tsconfig/package 信息。
- [ ] 修复后重新运行诊断并验证问题是否消失。
- [ ] 批量修复同类 Problems，避免修改不相关文件。
- [ ] 检测项目测试框架和测试目录约定。
- [ ] 生成测试后可直接运行对应测试任务并解析结果。

### 3.6 连续会话、Token 与上下文（未开发，P1）

- [ ] 每个工作区保存独立 AI 编辑会话。
- [ ] 展示用户指令、Agent 计划、工具调用和审阅结果。
- [ ] Token 估算、预算上限、文件占用明细和截断提示。
- [ ] 固定/取消固定上下文文件。
- [ ] 对话压缩和长会话恢复。
- [ ] API 取消、重试、超时与限流反馈。

### 3.7 AI 撤销与修改历史（部分完成，P0）

当前仅在内存中保存最近接受的整文件 before/after。仍需：

- [ ] 持久化 AI 修改历史并按会话分组。
- [ ] 多文件操作作为单个事务撤销/重做。
- [ ] 撤销前检测文件是否又被修改。
- [ ] 展示历史 Diff、指令、模型、时间和接受范围。
- [ ] 应用重启后恢复待审阅候选和历史。

## 4. 集成终端

### 4.1 Shell Profile（部分完成，P1）

已有 PowerShell/cmd/Git Bash 或 zsh/bash/fish 选择。仍需：

- [ ] 自动发现系统已安装 Shell，并隐藏不存在的 Profile。
- [ ] 自定义 Profile：路径、参数、图标、颜色和启动目录。
- [ ] 按工作区设置默认 Profile。
- [ ] Profile 创建失败时回退并给出可修复建议。

### 4.2 标签、重命名、排序与分屏（部分完成，P1）

- [ ] 使用应用内重命名输入框替代 `prompt`。
- [ ] 分屏支持水平/垂直方向和拖动调整比例。
- [ ] 一个组内多个 Pane，而不只两个终端。
- [ ] Tab/Pane 拖拽重组。
- [ ] 关闭包含运行任务的终端时确认。
- [ ] 终端复制、移动到新窗口暂不在范围内。

### 4.3 会话恢复（部分完成，P1）

当前只恢复标签标题、cwd 和 Profile，重新创建进程。仍需：

- [ ] 恢复终端序列化屏幕内容和滚动位置。
- [ ] 明确标识“恢复的历史内容”和“新进程”。
- [ ] 恢复 Pane 布局、活动终端和分屏比例。
- [ ] 异常退出后清理主进程残留 PTY。

### 4.4 工作区配置与环境变量（部分完成，P0）

- [ ] 环境变量编辑器支持增删行、校验变量名和隐藏敏感值。
- [ ] 区分全局、工作区和单 Profile 环境变量。
- [ ] 支持 `${workspaceFolder}` 等变量替换。
- [ ] 禁止把 Secret 明文写入普通 localStorage。
- [ ] 环境变化仅作用于新终端，并明确提示。

### 4.5 Tasks 与 Problem Matcher（部分完成，P1）

当前只读取根目录 `package.json` scripts，并用通用正则提取错误。仍需：

- [ ] 支持 `.vscode/tasks.json`、工作区自定义任务和多包项目 scripts。
- [ ] dependsOn、group、presentation、background 等任务属性。
- [ ] 可配置 Problem Matcher，支持 TypeScript、ESLint、Webpack、Vite、Go、Rust 等格式。
- [ ] 后台任务开始/结束检测。
- [ ] 任务运行历史、重新运行、终止和并发控制。
- [ ] Problems 与任务生命周期关联，重新运行时清除旧问题。

## 5. 文件资源管理器

### 5.1 布局与状态（部分完成，P1）

已有宽度拖动和宽度持久化。仍需：

- [ ] Explorer 最小化/恢复后的宽度与焦点一致。
- [ ] 多个 Explorer Section 的折叠状态。
- [ ] 拖动时覆盖层，避免 Monaco/iframe 抢占鼠标事件。

### 5.2 多选批量操作（部分完成，P0）

已有 Ctrl/Cmd 多选、Shift 连选、批量复制/剪切/移动/回收站。仍需：

- [ ] 粘贴名称冲突策略：覆盖、跳过、自动重命名、全部应用。
- [ ] 批量操作进度、取消和失败汇总。
- [ ] 防止父目录和其子项同时进入批量集合。
- [ ] 大目录复制使用后台任务，不能阻塞主进程。
- [ ] 批量重命名。

### 5.3 图标和装饰（部分完成，P1）

已有常见扩展名颜色和 Git/错误/警告数字。仍需：

- [ ] 完整文件图标映射与可切换图标主题。
- [ ] 目录图标按名称区分 src、test、assets、config 等。
- [ ] Git 状态颜色和符号符合 staged/unstaged/conflict 状态。
- [ ] 父目录聚合子项装饰。
- [ ] 装饰 Tooltip 和无障碍文本。

### 5.4 排序、过滤和紧凑目录（部分完成，P1）

已有 name/type 排序和内存过滤数据结构，但 UI/持久化尚未完成。仍需：

- [ ] Explorer 工具栏提供排序和过滤入口。
- [ ] 支持 name、type、modified、folders first、mixed。
- [ ] 支持 glob 排除和 `files.exclude`。
- [ ] 紧凑目录把单子目录链显示为 `a/b/c`，并正确处理展开、选择和重命名。
- [ ] 过滤模式高亮匹配文本并保留父路径。

### 5.5 多根工作区与最近工作区（未开发，P1）

- [ ] Workspace 模型从单 root 改为 folders 数组并分配稳定 folder ID。
- [ ] Add Folder、Remove Folder、Save Workspace、Open Workspace File。
- [ ] 所有文件、搜索、Git、终端 API 明确所属根目录。
- [ ] 多根目录分别监听、分别恢复展开状态和设置。
- [ ] 最近工作区列表、固定、移除、路径失效提示。
- [ ] 切换工作区前统一处理未保存文档、任务和终端。

### 5.6 文件系统入口（部分完成，P1）

已有 HEAD 比较、文件时间线、Reveal、Copy Path 和 Copy Relative Path。仍需：

- [ ] 任意两个文件比较和“与活动文件比较”。
- [ ] 使用系统默认应用打开。
- [ ] Reveal 失败和文件已删除时的反馈。
- [ ] Windows/macOS/Linux 路径显示格式与剪贴板错误处理。

## 6. 工作区搜索

### 6.1 分组、折叠和历史（部分完成，P1）

已有按文件分组、折叠、结果数量和最近 30 条搜索历史。仍需：

- [ ] 全部展开/折叠和记忆折叠状态。
- [ ] 搜索历史管理：删除单条、清空、前后导航。
- [ ] 替换历史独立保存。
- [ ] 高亮预览中的匹配片段。

### 6.2 单项、单文件和批量替换（部分完成，P0）

已有三个粒度的替换入口和内存撤销快照。仍需：

- [ ] 单项替换后只刷新受影响结果，保持滚动位置。
- [ ] 替换捕获组、零宽正则和多行正则的完整测试。
- [ ] 只读、外部变更和部分失败时的事务策略。
- [ ] 撤销历史持久化，并限制磁盘/内存占用。
- [ ] 替换新建/删除行后正确重算后续结果位置。

### 6.3 替换预览（未开发，P0）

- [ ] 执行批量替换前生成文件级 Diff。
- [ ] 文件/Hunk 级勾选需要应用的替换。
- [ ] 展示预计文件数、匹配数和冲突文件。
- [ ] 预览期间文件变化时标记结果过期并禁止直接应用。

### 6.4 Glob 与 ignore（部分完成，P1）

已有基础 `*`、`**`、`?` 以及根目录 `.gitignore`、`.ignore`。仍需：

- [ ] 完整 gitignore 语义：否定规则、目录相对规则、转义和嵌套 ignore 文件。
- [ ] include/exclude 使用统一 Glob 库并提供语法错误反馈。
- [ ] `search.exclude`、`files.exclude` 和是否遵循 ignore 的设置开关。
- [ ] 符号链接、子模块、隐藏文件和二进制文件策略。
- [ ] 使用 ripgrep 或 Worker，避免主进程同步遍历大型仓库。

### 6.5 搜索编辑器（未开发，P2）

- [ ] 将搜索结果打开为可保存的 Search Editor 标签。
- [ ] 支持上下文行数量、重新搜索和结果排序。
- [ ] 双击结果跳回源文件，保持行列位置。
- [ ] Search Editor 内容不是普通文件，不能误写入工作区。

## 7. 横向技术债与验证

- [ ] 将过大的 `CodeEditorPanel.tsx` 继续拆分为 Git、AI、Terminal、Explorer Controller/Panel。
- [ ] 用应用内 Modal/Confirm 替换所有 `window.prompt`、`window.confirm`。
- [ ] Git、搜索和批量文件操作从同步主进程调用迁移到可取消后台任务。
- [ ] 为 Git Patch/Hunk、Glob、替换偏移、AI JSON 校验添加单元测试。
- [ ] 为分支切换、冲突合并、多文件 AI、任务终端增加 Electron 集成测试。
- [ ] 增加大型仓库性能基准：1 万、10 万文件。
- [ ] 完善 IPC 授权：不能只依赖 Renderer 传入 rootPath，应在主进程维护已授权工作区集合。
- [ ] 修复项目既有 `electron-squirrel-startup` 类型和 Forge 全局声明错误，使全量 TypeScript 检查归零。
- [ ] Monaco、TS Worker、xterm 体积较大，需要代码分包和按需加载。

## 8. 推荐实施批次

1. **批次 A：安全闭环**：Merge Result 编辑、替换预览/事务撤销、AI Patch/Hunk 审阅、Git 操作队列与取消。
2. **批次 B：工作流闭环**：Commit 文件 Diff、分支/上游管理、Tasks/Matcher、多根工作区基础模型。
3. **批次 C：效率增强**：Inline Edit、语义上下文搜索、Explorer 高级过滤、Search Editor。
4. **批次 D：体验与性能**：会话持久化、图形历史、终端屏幕恢复、大仓库索引和按需加载。
