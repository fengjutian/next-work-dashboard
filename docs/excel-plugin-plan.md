# Excel 预览编辑插件 — 技术方案

## 1. 目标

在 next-work-dashboard 中新增一个**系统级内置插件** ，提供纯前端的 Excel 文件（.xlsx / .xls）预览与编辑能力，支持保存回本地。

## 2. 技术选型

### 社区 Excel 库对比（2025年7月）

| 库 | Stars | React | 编辑/公式 | 导入导出 | 许可 | 体积 |
|---|---|---|---|---|---|---|
| **SheetJS (xlsx)** | 36.3k | 仅数据 | 无UI | 最全格式 | Apache 2.0 | ~500KB |
| **ExcelJS** | 15.4k | 仅数据 | 无UI | 样式更好 | MIT | ~400KB |
| **Handsontable** | 22k | 官方 | 400+公式 | ✅ | 非商用免费 | ~1MB |
| **Univer** | 14k | 18/19 | 公式引擎 | ⚠️ Pro | Apache 2.0 | 多包~2MB |
| **Fortune-sheet** | 3.7k | ✅ | ✅ | ✅ | MIT | ~800KB |
| **RevoGrid** | 3.4k | ✅ | ⚠️ Pro | CSV/PDF | MIT | ~200KB |

### 本项目选型决策

| 维度 | 决策 | 原因 |
|---|---|---|
| 文件读写 | **SheetJS (xlsx)** | 已是项目依赖（v0.18.5），36k+ stars，被 Microsoft 使用 |
| 表格 UI | **自研轻量 Grid** | 避免引入重型依赖，符合项目最小依赖原则 |
| 编辑方式 | **内联编辑** | 点击单元格进入编辑态，Tab/Enter 导航 |

## 3. 功能范围

### V1（本次实现）

| 功能 | 描述 |
|------|------|
| 打开文件 | 文件选择器 + 拖拽 .xlsx/.xls |
| 多 Sheet | Sheet 标签栏切换 |
| 表格渲染 | 虚拟行渲染 |
| 单元格选中 | 点击选中，方向键移动 |
| 内联编辑 | 双击或 Enter 进入编辑态 |
| 行列标题 | A/B/C 列标 + 1/2/3 行号 |
| 保存 | 覆盖写回原文件 |
| 另存为 | 文件保存对话框 |
| 撤销/重做 | 操作历史栈 |
| 添加/删除行列 | 工具栏按钮 |

### V2（后续）

- 公式栏（fx编辑栏）
- 选区复制粘贴
- 单元格样式
- 列宽拖拽调整
- 筛选排序
- CSV 导入导出
