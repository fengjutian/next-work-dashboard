把工作流，装进一个桌面工作台

Next Work Dashboard 是面向 AI 协作的 Electron 桌面应用。这里汇集安装部署、功能使用、插件架构、安全规范与开发参考。

开始使用 → 了解项目 
$ git clone https://github.com/fengjutian/next-work-dashboard.git
$ cd next-work-dashboard/prompt-lab
$ npm install
$ npm start

✓ Electron workspace is ready
